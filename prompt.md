I am building an enterprise RAG (Retrieval-Augmented Generation) application named "Intelligent Knowledge Hub" in Python using FastAPI, Azure AI Search, and Azure OpenAI, with automated CI/CD deployment via GitHub Actions to an Azure Linux App Service (B1 tier).

This project serves as a portfolio piece showcasing AI Enablement leadership, Microsoft AI-103 (Azure AI Engineer), and AZ-104 (Azure Administrator) competency under a strict zero-additional-cost constraint.

### Project Context & State:
- GitHub Repository: `https://github.com/N8Space/intelligent-knowledge-hub`
- Azure App Service: `intelligent-knowledge-hub` (Linux Python runtime)
- Ingestion (`ingest.py`): Completed (39 vectorized chunks indexed in Azure AI Search).
- Search Index: `kb-index` (fields: `id`, `title`, `content`, `contentVector` [1536 dims, HNSW profile `kb-vector-profile`]).
- Azure OpenAI Endpoint: `https://kb-openai-lester-labs.openai.azure.com/`
- Azure Search Endpoint: `https://kb-search-hub.search.windows.net`
- Embeddings Model Deployment: `text-embedding-3-small`

- Authentication: Passwordless Microsoft Entra ID authentication via `DefaultAzureCredential()` and `get_bearer_token_provider(credential, "https://cognitiveservices.azure.com/.default")`.

### Deliverables to Implement:

#### 1. Backend Engine (`main.py` - FastAPI)
- **Zero-Trust Client Init:** Initialize `DefaultAzureCredential`, `token_provider`, `AzureOpenAI`, and `SearchClient`.
- **CORS & Static Files:** Add CORS middleware and mount `/static` directory to serve the frontend UI.
- **Enterprise Probes:**
  - `GET /health/live`: Simple liveness probe returning `{ "status": "healthy" }`.
  - `GET /health/ready`: Deep readiness probe checking live connectivity to Azure AI Search and Azure OpenAI endpoints.
- **Hybrid Search & Generation (`POST /query`):**
  - Accepts JSON payload: `{"question": "string", "top_k": 3}` (default `top_k=3`).
  - Measures end-to-end telemetry (retrieval latency, generation latency, total time).
  - Generates query vector via `text-embedding-3-small`.
  - Executes **Hybrid Search (BM25 keyword + Vector via RRF)** against `kb-index` using `VectorizedQuery` alongside `search_text`.
  - Constructs a grounded system prompt instructing `gpt-5.4-mini` to answer strictly based on retrieved context and cite source documents accurately.
  - Returns structured JSON:
    - `answer`: Grounded response text.
    - `citations`: List of unique document titles (`title`) and chunk IDs.
    - `context`: Retrieved text passages.
    - `metrics`: Object containing retrieval latency (ms), LLM latency (ms), total latency (ms), prompt tokens, completion tokens, and estimated query cost ($0.0000X).
- **User Feedback & Dataset Flywheel (`POST /feedback`):**
  - Accepts JSON payload: `{"query": "string", "response": "string", "citations": list, "retrieved_context": list, "rating": "like" | "dislike", "reason": str | null, "user_correction": str | null}`.
  - Formats record with timestamp and exports it as a JSON Lines entry to `data/feedback_dataset.jsonl`.
  - Structures positive feedback for automated ingestion into a "Golden Answer Evaluation Set" (`tests/golden_eval_set.jsonl`) and negative/corrected feedback into a "Direct Preference Optimization (DPO) / SFT Tuning Set".
  - `GET /feedback/stats`: Returns summary counts of recorded positive, negative, and human-corrected feedback records.

#### 2. Interactive Single-Page UI (`static/index.html`, `static/app.js`, `static/styles.css`)
- Clean, modern dashboard interface served directly by FastAPI at `/`:
  - **Main Interaction Area:**
    - Search input box with sample prompts and a submit button.
    - Live response card displaying the grounded answer generated by `gpt-5.4-mini`.
    - **Interactive Feedback Controls:** Thumbs-up / Thumbs-down buttons directly under the answer.
      - Clicking 👍 provides immediate visual confirmation and sends feedback payload.
      - Clicking 👎 opens an inline drawer with optional issue tags (`[ ] Inaccurate Fact`, `[ ] Missing Info`, `[ ] Wrong Document Cited`) and a text area for human ground-truth corrections.
  - **AI Enablement & Observability Sidebar:**
    - **Traceability & Citations:** Real-time source document badges with chunk references for auditability.
    - **Performance & FinOps Metrics:** Real-time display of retrieval latency, LLM response latency, prompt/completion token counts, and calculated query unit cost.
    - **LLMOps Data Flywheel Counter:** Real-time tally showing active dataset curation status (e.g., `Golden Test Records: X`, `DPO Preference Pairs: Y`).
    - **Business Outcome Indicators:** Visual KPI summary (e.g., Target vs Actual First Contact Resolution, CSR Search Time Reduction).
